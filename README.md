
# ISMAI - Marketing e Comunicação Digital

> Repositório do projeto de Marketing e Comunicação Digital do ISMAI, contendo o site institucional, políticas de privacidade, campanhas de e-mail e recursos visuais.

---

## Estrutura do Projeto

- **app ismai/**
  - Arquivos principais do site: `index.html`, `index_novo.html`, `website-index.html`, `privacy-policy.html`, `cookies-policy.html`, `app.js`, `data.js`, `styles.css`, `website-script.js`, `website-styles.css`.
  - **assets/**: Imagens, ícones e outros recursos estáticos.
  - **E-mail Marketing/**: Campanhas e modelos de e-mail, como `email-marketing-maieutica.html`.

---

## Como Utilizar

1. **Clone o repositório:**
  ```sh
  git clone https://github.com/seu-usuario/seu-repositorio.git
  ```
2. **Acesse a pasta do projeto:**
  ```sh
  cd "app ismai"
  ```
3. **Abra o arquivo desejado no navegador:**
  - Para visualizar a app e o site, abra `index.html` ou `website-index.html`.
  - Para campanhas de e-mail, acesse a pasta `E-mail Marketing/`.

---

## Personalização

- Edite os arquivos HTML, CSS e JS conforme necessário para adaptar o conteúdo ao seu público.
- Adicione novos recursos em `assets/` para imagens ou ícones personalizados.
